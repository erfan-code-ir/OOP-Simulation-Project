
# OOP Simulation Project 🚀
This project is a professional simulation of a work environment implemented using advanced Object-Oriented Programming (OOP) principles in Python.

## 🌟 Key Features:
- Inheritance: Deep use of base classes for `Person` and `WorkPlace`.
- Polymorphism: Dynamic implementation of capacity and cost calculations across different business types (School, Mine, Company).
- Custom Exception Handling: Robust error management for workplace overflow.
- Bi-directional Relationships: Smart linkage between employees and their respective workplaces.
- Complex Mathematical Models: Implementing various growth and decay functions for income and costs based on age and experience.

## 📂 Project Structure:
- `person.py` & `worker.py` / `teacher.py` / `engineer.py`: The human resource hierarchy.
- `work_place.py` & `school.py` / `mine.py` / `company.py`: The business environment hierarchy.
- `consts.py`: Centralized configuration for all base prices and multipliers.
- `main.py`: The main execution script.

## 🛠️ How to Run:
1. Clone the repository:
   git clone https://github.com/erfan-code-ir/OOP-Simulation-Project.git
   
2. Run the main script:
   python main.py
